# جدول يومي تفاعلي

مشروع Flutter جديد بمعرّف الحزمة `com.myapp132.app`. الاسم الظاهر المؤقت هو «جدولي اليومي» ويمكن تغييره لاحقًا.

## الميزات

- واجهة عربية RTL في الصفحة الرئيسية.
- كتابة وتعديل المهام مباشرة داخل الصفحة.
- Enter يضيف سطرًا داخل المهمة ولا ينشئ مهمة جديدة.
- حفظ محلي باستخدام SharedPreferences.
- تاريخ مستقل لكل يوم مع الرجوع للأيام السابقة والقادمة.
- وقت بداية اختياري لكل مهمة.
- ألوان مستقلة، حالات: غير محددة/مكتملة/غير مكتملة، وتكرار يومي اختياري.
- أقسام نهاية اليوم قابلة للطي.
- إشعارات محلية عند وقت البداية ضمن قيود Android وتوفير الطاقة.
- لا يوجد Gemini أو API Key أو تسجيل دخول أو خدمة سحابية.

## البناء

افتح المجلد الذي يحتوي على `pubspec.yaml` في محرر Flutter، ثم نفذ `flutter pub get` وبعدها Build APK. Workflow GitHub لا يطلب أي Secret ولا يحتوي على خطوة تحقق من API.

لم يتم الادعاء ببناء APK في هذه البيئة؛ يجب تنفيذ `flutter pub get` و`flutter analyze` و`flutter build apk --release` في بيئة Flutter فعلية.
